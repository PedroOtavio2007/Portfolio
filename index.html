Projeto pessoal full-stack

Sistema de Agendamento para Barbearias

Ver repositório

Aplicação web para digitalizar o agendamento de serviços e a gestão de horários, com painéis separados para clientes e barbeiros.

Principais implementações técnicas

  • Segurança e autenticação: acesso por perfil (cliente e administrador), verificação de conta por e-mail (double opt-in) e recuperação de senha com tokens.
  • Back-end e banco de dados: modelagem relacional, APIs RESTful serverless e Prisma com PostgreSQL na nuvem.
  • Interface: telas responsivas com tema escuro e dashboard do barbeiro para controlar a agenda do dia.
  • Next.js
  • TypeScript
  • Tailwind CSS
  • Prisma
  • PostgreSQL
