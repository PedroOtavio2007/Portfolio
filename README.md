# 💻 Portfólio Pessoal | Pedro Otávio

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar minhas habilidades técnicas, projetos acadêmicos e colaborativos, além das minhas principais formas de contato.

🚀 **Acesse o site ao vivo:** [pedro-ramos.vercel.app](https://pedro-ramos.vercel.app/)

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3 & Tailwind CSS:** Estilização moderna, utilitária e totalmente responsiva.
- **JavaScript:** Interatividade e comportamentos dinâmicos na página.
- **Vercel:** Hospedagem e deploy contínuo integrado ao GitHub.

---

## 📌 Sobre o Projeto

O site possui uma estrutura *single-page* (página única), leve e responsiva, organizada nas seguintes seções:

- **Sobre Mim:** Resumo do meu perfil acadêmico em Engenharia de Computação e objetivos profissionais.
- **Projetos em Destaque:** Detalhamento das minhas contribuições técnicas em aplicações mobile e repositórios de código.
- **Habilidades:** Principais linguagens (TypeScript, React Native, Python, C) e ferramentas (Git/GitHub, VS Code).
- **Contato:** Acesso direto às minhas redes profissionais e envio de e-mail.
